Task: "Build a desktop calculator app in Python using Tkinter only (no external GUI libraries). Provide a runnable entry file main.py with `if __name__ == '__main__':` that starts the app. The UI must include a visible display widget and clickable buttons for digits 0-9, '+', '-', '*', '/', '.', '=', clear, and backspace. Use button labels exactly: C for clear and ⌫ for backspace. Clicking digit/operator buttons must update the display, and clicking '=' must evaluate the current expression and replace the display with the computed result. Required behaviors: 2+3=5, 9-4=5, 3*4=12, 8/2=4, decimal math (1.5+2.5=4), clear resets display to empty or 0, backspace removes one character, chained operations work (2+3+4=9), and division by zero shows an error message in the display (contains 'error' or 'zero'). Code must run directly with Python 3.10+ and include all required imports (including `import tkinter as tk`) with no NameError at startup.".

### Step-by-Step Plan

1. **Core Classes and Functions:**
   - `CalculatorApp`: Main application class that initializes the GUI components.
   - `update_display(value)`: Updates the display with a new value.
   - `clear_display()`: Clears the display.
   - `backspace()`: Removes the last character from the display.
   - `evaluate_expression()`: Evaluates the current expression in the display and updates it with the result.

2. **File Structure:**
   - `main.py`: Entry point of the application.
   - `calculator.py`: Contains the `CalculatorApp` class.

#### calculator.py
```python
import tkinter as tk

class CalculatorApp:
    def __init__(self, master):
        self.master = master
        self.master.title("Calculator")
        
        # Display widget
        self.display = tk.Entry(master, width=40, borderwidth=5)
        self.display.grid(row=0, column=0, columnspan=4, padx=10, pady=10)
        
        # Button labels and their corresponding functions
        buttons = [
            ('7', lambda: self.update_display('7')),
            ('8', lambda: self.update_display('8')),
            ('9', lambda: self.update_display('9')),
            ('/', lambda: self.update_display('/')),
            ('4', lambda: self.update_display('4')),
            ('5', lambda: self.update_display('5')),
            ('6', lambda: self.update_display('6')),
            ('*', lambda: self.update_display('*')),
            ('1', lambda: self.update_display('1')),
            ('2', lambda: self.update_display('2')),
            ('3', lambda: self.update_display('3')),
            ('-', lambda: self.update_display('-')),
            ('0', lambda: self.update_display('0')),
            ('.', lambda: self.update_display('.')),
            ('=', self.evaluate_expression),
            ('C', self.clear_display),
            ('⌫', self.backspace)
        ]
        
        # Create buttons and place them in the grid
        row_val = 1
        col_val = 0
        for (text, command) in buttons:
            button = tk.Button(master, text=text, width=10, height=3, command=command)
            button.grid(row=row_val, column=col_val, padx=5, pady=5)
            col_val += 1
            if col_val > 3:
                col_val = 0
                row_val += 1

    def update_display(self, value):
        current_value = self.display.get()
        new_value = current_value + str(value)
        self.display.delete(0, tk.END)
        self.display.insert(0, new_value)

    def clear_display(self):
        self.display.delete(0, tk.END)
        self.display.insert(0, '0')

    def backspace(self):
        current_value = self.display.get()
        if len(current_value) > 1:
            new_value = current_value[:-1]
        else:
            new_value = '0'
        self.display.delete(0, tk.END)
        self.display.insert(0, new_value)

    def evaluate_expression(self):
        try:
            result = eval(self.display.get())
            self.display.delete(0, tk.END)
            self.display.insert(0, str(result))
        except ZeroDivisionError:
            self.display.delete(0, tk.END)
            self.display.insert(0, 'error: zero division')
        except Exception as e:
            self.display.delete(0, tk.END)
            self.display.insert(0, f'error: {str(e)}')

```

### Explanation

- **main.py**: This file serves as the entry point for the application. It initializes the Tkinter root window and creates an instance of `CalculatorApp`.
  
- **calculator.py**: This file contains the `CalculatorApp` class, which sets up the GUI components and handles user interactions. The class includes methods to update the display, clear it, handle backspace, and evaluate expressions.

This setup ensures that the calculator application meets all the specified requirements and functions correctly with Python 3.10+.
